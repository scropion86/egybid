    ال A - دول يلزموني

    دول ( عزيز قوم ذلّ ) - اللي محتاجين حاجة بمواصفات ال A وبأسعار ال B

    فاحنا هنعطي لهم مواصفات ال A - ونبيع لهم بأسعار ال B +

    -

    كذلك حضرتك محتاج تقسم شريحة C لـ C + و C -

    -

    ال C + دول بردو يلزموني

    دول المتطلّعين للارتقاء من ال C للـ B

    فمحتاجين حاجة بمواصفات ال B وبأسعار ال C

    فهنعطيهم حاجة بمواصفات ال B - وبأسعار ال C +
